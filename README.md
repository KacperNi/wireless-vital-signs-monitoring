# Wireless vital signs monitoring system
The work concerns the design and implementation of a portable device for
monitoring basic vital signs, such as body temperature, heart rate, and blood
oxygen saturation. The system was implemented using an ESP32 microcontroller
and MAX30102 and DS18B20 sensors, while the measurement data is transmitted
wirelessly to an online platform that allows for real-time visualization. The device is
designed as a wearable wristband. Its correct operation was verified experimentally
by comparing the measurement results with data obtained from reference devices
and by analyzing the influence of external factors.
